# Telegram-bot-weather
Примитивный телеграм бот для просмотра погоды.

Предварительно необходимо создать бота через @BotFather.
Далее необходимо скопировать API ключ и создать файл config.py в котором необходимо прописать api_key = скопированный ключ и сохранить.
Следующим шагом будет запуск бота через python3 main.py. Теперь необходимо найти своего бота по его юзернейму, нажать /start и просматривать погоду.
